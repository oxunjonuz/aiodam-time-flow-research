## 2. Пункт 1 — `h3_imr_spins.py`, `art_d8f0b19dced3`

Конверт по спинам — **не прямоугольник**: a1 и a2 связаны через χ_eff = −0.07 ± 0.17.
Угол (0.69, 0.89) несёт χ_eff = +0.78 и исключён измерением. Скан:
`|a1| ≤ 0.69, |a2| ≤ 0.89, χ_eff ∈ [−0.24, +0.09]`, 58 точек.

| набор | χ_eff | ρ_opt (H1) | /ρ_opt(0) |
|---|---:|---:|---:|
| zero | 0.000 | 31.6595 | 1.0000 |
| χ_eff median | −0.070 | 31.1073 | 0.9826 |
| medians | +0.373 | 34.8362 | 1.1003 |
| bounds (вне χ_eff) | +0.778 | 38.5973 | 1.2191 |
| bounds_low (вне χ_eff) | −0.778 | 26.5692 | 0.8392 |

**Спинами опубликованное С/Ш не достигается**, и наибольший спиновой эффект
двигает число **вверх**. Наклонение объясняет H1: 19.5 при **ι ≈ 59.8°**.
Множитель наклонения равен **(1+cos²ι)/2 точно** и не зависит от спинов
(3.3·10⁻¹⁶) — поэтому совместный диапазон точен, а не выборочен.

Отношение опубликованных С/Ш 1.466 против 1.102 (оптимальные) и 1.303
(извлечённые фильтром): остаток — **отклик антенн**, которого в модели нет.

## 3. Пункт 2 — `h3_direct_fit_imr.py`, `art_fd571ae9919b`

**Решение, а не косметика:** τ(t) нужен момент времени на частоте. Инспиральная
формула уходит в 0 (`t_PN(250 Гц) = −1.0 мс`), IMR **выходит на плато**
(`t_IMR(250 Гц) = −155 мс`). Отношение 1.03 → **155**. Посчитаны обе конвенции.

| шаблон / ядро / сетка | drop H1 | drop L1 | граница |
|---|---:|---:|---|
| LO / pn / ±9.6 мс | 0.213 | 0.046 | нет |
| LO / pn / ±38.4 мс | 0.791 | 0.461 | нет |
| IMR / pn / ±9.6 мс | 0.668 | 0.506 | нет |
| **IMR / pn / ±38.4 мс** | **2.925** | **2.144** | **да** |
| **IMR / imr / ±38.4 мс** | **1.371** | **1.047** | **да** |

**Ответ рецензенту расщепляется по шаблону — это и есть находка.** С ведущим
инспиралом ограничений нет ни на одной сетке. С полным IMR на сетке ±38.4 мс
профиль падает больше чем на 1σ в одну сторону: **односторонняя граница**
≈ −10…−13 мс (H1) и +19…+37 мс (L1). Первый раз проект извлёк из данных
ограничение на τ₂, а не из аргумента физичности.

**Контроль мощности:** тот же фит восстанавливает инжекцию 20 мс (21.75 / 20.17)
и **не** восстанавливает 1.2 мс (0.15 / −0.56 при разбросе 4–5 мс).

## 4. Мои пять ошибок, все пойманы контролем

1. `irfft` вместо `ifft` → пик занижен в 16384 раза (**NC6**).
2. `B = zeros(seg_n)` с маской длины rfft → тихое несовпадение длин (**NC6**).
3. `template_time_series` делил на `fs` → круговой прогон давал σ/fs (**NC7**).
4. Сетка ±9.6 мс для инжекции 20 мс → край сетки как ответ (**NC4**).
5. Верификатор: двухступенчатый поиск пика **тихо пропустил максимум**
   (7.8106 вместо 8.2011) → удалён.

**Ложный критерий записан, не удалён:** NC6 первого черновика («больше мощности
→ не меньше пик») **ложен** — спины поднимают ρ_opt 31.66 → 34.84, а пик падает
16.74 → 13.51, потому что меняется фаза. Заменён на Коши — Шварца.
