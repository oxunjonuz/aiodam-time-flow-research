## 2. Модель, на которой всё считается

Фазовый член частотной развёртки слияния, ведущий порядок:

```
Ψ(f) = 2π f t_c − φ_c − π/4 + (3/128)(π M_c f)^(−5/3)
```

где `M_c` — масса чирпа, `t_c` — время коалесценции, `φ_c` — фаза коалесценции.

Предсказание «now»-теории: излучение задержано на `τ(t)`, где `t` — момент
излучения. В частотной области это даёт аддитивную поправку к фазе

```
ΔΨ(f) = 2π f τ(t(f)),      t(f) = t_c − (5/256) M_c^(−5/3) (π f)^(−8/3)
```

Ключевое: **все параметры (M_c, t_c, φ_c) в анализе LIGO подгоняются свободно.**
Вопрос идентифицируемости — лежит ли вектор `ΔΨ` в линейной оболочке векторов
`∂Ψ/∂M_c`, `∂Ψ/∂t_c`, `∂Ψ/∂φ_c`.

## 3. Гипотезы (заморожены)

**H1 — точное вырождение постоянной задержки.**
Постоянная задержка `τ(t) ≡ τ_0` даёт `ΔΨ = 2π f τ_0`, что **тождественно**
равно сдвигу `t_c → t_c + τ_0`. Следовательно, `τ_0` не идентифицируем ни при
каком отношении сигнал/шум и ни при какой кривой шума.
*Фальсификатор:* предъявить функционал от `h(f)`, чувствительный к `τ_0` и
нечувствительный к `t_c`. Предсказание: такого функционала не существует.

**H2 — точное вырождение линейно растущей задержки.**
Если `τ(t) = τ_0 + τ̇(t − t_ref)`, то член `∝ τ̇` даёт
`ΔΨ = −(5/3) τ̇ · Ψ_chirp + (член ∝ f)`, то есть **тождественно** эквивалентен
перемасштабированию массы чирпа
`M_c → M_c (1 − (5/3)τ̇)^(3/5) ≈ M_c (1 − τ̇)`.
Следовательно, `τ̇` не идентифицируем отдельно от `M_c`.
*Фальсификатор:* показать, что остаток после наилучшей подгонки по `M_c` при
внедрённом `τ̇ ≠ 0` отличен от нуля больше машинной точности.

**H3 — идентифицируемо только второе и высшие порядки.**
Для гладкой `τ(t)` вклад в фазу разлагается по степеням `(π M_c f)^(2/3)`; члены
нулевого и первого порядка по `t` вырождены (H1, H2), а остаток подавлен
относительно ведущей фазы множителем порядка `(v/c)²`.
*Фальсификатор:* показать, что квадратичный член даёт остаточное С/Ш ≥ 1 на
GW150914 при шуме aLIGO и при величине эффекта, заявленной статьёй.

**H4 — количественная оценка статьи не имеет заявленной точности.**
Статья даёт 1–1.5 мс. Проверяю: (а) «размерный анализ» (0.6 мс) и «расчёт по
Шварцшильду» (1.2 мс) — не независимые оценки, а отличаются ровно
геометрическим множителем `(ΔV)^(1/3)/Rs`; (б) множитель 1.5/1.2 = 1.25
вводится словами «with the additional gravitational redshift» без вывода.
*Фальсификатор:* найти в статье вывод множителя 1.25 или показать, что
`(ΔV)^(1/3)/Rs(62) = 1`.

**H5 — возражение относительности одновременности к «растущему блоку».**
Если «существующее сейчас» — пространственноподобная гиперповерхность (край
роста), то в 1+1-мерной геометрии Минковского для любых двух событий с
`|Δt| < |Δx|/c` найдутся инерциальные системы, в которых знак `Δt'`
противоположен. Следовательно, предикат «существует» не может быть одновременно
(а) инвариантным и (б) равным «лежит в прошлом края».
*Фальсификатор:* предъявить инвариантный предикат на событиях, совпадающий с
«в прошлом края» в одной системе и не зависящий от системы.

## 5. Негативные контроли (каждый должен краснеть)

1. **К1 — нулевая инъекция.** τ = 0 → остаток ровно 0.
2. **К2 — откат H1.** Фиксирую `t_c` → остаток от постоянной задержки ненулевой.
3. **К3 — откат H2.** Фиксирую `M_c` → остаток от линейной задержки ненулевой.
4. **К4 — перемешанная фаза.** Случайная гладкая добавка → остаток большой.
5. **К5 — усиление ×100.** Квадратичный эффект ×100 → обнаруживается (T6).
6. **К6 — подмена знака.** τ̇ → −τ̇ → остаток такой же нулевой.
7. **К7 — чужая кривая шума.** Другая S_n(f) → корреляции остаются 1.

## 6. Формализация (Lean 4 + Mathlib)

`work/lean/Identifiability.lean`:

- **T_ident.** Для `M(θ,τ) = A θ + B τ`: `τ` идентифицируем
  (⟺ `M(θ,τ) = M(θ',τ') ⟹ τ = τ'`) **тогда и только тогда**, когда `B`
  инъективно и `range A ⊓ range B = ⊥`.
- **C1.** Если `range B ≤ range A`, то `τ` не идентифицируем.
- **C2.** Если `B` инъективно и `range A ⊓ range B = ⊥`, то `τ` идентифицируем.

`work/lean/RelativityOfNow.lean`:

- **T_sim.** В 1+1 Минковском: если `|Δt| < |Δx|/c`, то существует буст
  (|v| < c), меняющий знак `Δt' = γ(Δt − vΔx/c²)`.

Обе теоремы — без `sorry` и без `axiom`. Наличие `sorry` = провал
формализации, а не частичный успех.
