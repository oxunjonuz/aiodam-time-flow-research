## 1. Два структурных факта

**(а) Соглашение phenomxpy (измерено).** `hp = A(ι)e^{2iφ}hp₀`,
`hc = B(ι)e^{2iφ}hc₀`, `hc₀ = −i·hp₀` (откл. 3.3·10⁻⁴). Отсюда
`F₊hp + F×hc = e^{2iφ}hp₀(F₊A − iF×B)` — **весь отклик детектора сворачивается
в один комплексный коэффициент** `C_d = F₊A − iF×B`.

**(б) Отсюда же — когерентная статистика.**
`ρ_coh² = |Σ_d conj(C_d)ζ_d|² / Σ_d |C_d|²s_d²`, где `ζ_d` не зависит от `C_d`.
Считается один раз на `(M_c, τ₂)`, сетка `(ι, ψ)` бесплатна.

**Следствие:** `φ_c` умножает `C_d` каждого детектора на одну и ту же фазу →
**не идентифицируем** в когерентном фите с фиксированным положением. Названо
находкой, а не спрятано.

## 4. Шесть ошибок, все пойманы контролем

1. не учтён световой ход → когерентный С/Ш 12.0 **ниже** некогерентного 21.1 (NC9);
2. знак светового хода угадан, а не измерен (14.3 против правильных 21.08);
3. NC1 сравнивал IMR-шаблон с записанным числом **LO**-шаблона;
4. **ложный критерий** NC8: «не восстановлено» через среднее вместо разброса;
5. ручная реализация HEALPix — две попытки, обе неверны (пиксель 0 на 0.09° вместо 89.93°);
6. верификатор: спутаны `rfft(x)` и `rfft(x)/fs` (фактор `fs` во всех проверках).

**Пятая — самая полезная:** ручная реализация HEALPix **удалена**, а не отлажена.
